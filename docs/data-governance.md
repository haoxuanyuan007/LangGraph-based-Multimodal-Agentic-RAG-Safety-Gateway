# Data governance

The system separates source registration, derived knowledge, case memory, vulnerability intelligence, and evaluation data. Every admitted record must preserve provenance, upstream version, license status, retrieval time, checksum, location, transformation chain, synthetic flag, review state, and split where applicable.

Unknown-license, damaged, suspicious, or quality-failing sources enter quarantine. Dataset splits are assigned by source document or sample family before indexing, followed by exact, near-duplicate, perceptual-hash, and embedding leakage audits.

No dataset or external source is currently admitted; license review and manifests will be added source by source.

# Retrieval experiments

Planned comparisons include BM25, dense, hybrid/RRF, reranking, image-text shared embeddings, and page-level visual retrieval, together with fixed-token, overlap, structural, parent-child, table, page, and resource-permitting late chunking strategies.

Experiments must save configurations, tokenizer, chunk statistics, index cost, latency, raw results, and document/page/chunk and citation metrics. No model or strategy is currently designated as best.
